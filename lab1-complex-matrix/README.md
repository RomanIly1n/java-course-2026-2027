# Матрицы комплексных чисел

## Структура проекта

```
ComplexMatrixLab
├── src
│   ├── Complex.java        комплексное число и арифметика над ним
│   ├── ComplexMatrix.java  матрица комплексных чисел и операции над ней
│   └── Main.java           консольный интерфейс
├── .gitignore
└── README.md
```

## Возможности

- сложение матриц;
- умножение матриц;
- деление матриц (A / B = A · B⁻¹), если оно возможно;
- транспонирование;
- вычисление определителя методом Гаусса;
- консольное меню: ввод двух матриц (A и B), выбор операции, вывод результата.


### Complex

Неизменяемый класс (после создания поля не меняются). Хранит вещественную часть `re` и мнимую часть `im`.
Методы: `add`, `subtract`, `multiply`, `divide`, `negate`, `conjugate`, `abs` (модуль), `isZero`, `toString`.
Деление на ноль (модуль меньше 1e-10) приводит к `ArithmeticException`.

### ComplexMatrix

Неизменяемая матрица. Каждая операция возвращает новую матрицу, исходные не меняются.
Методы: `add`, `multiply`, `divide`, `transpose`, `determinant`, `inverse`, `isSquare`, `getRows`, `getCols`, `get`.

### Main

Меню и ввод с клавиатуры. Все ошибки пользователя (неверный формат, несовместимые размеры, вырожденная матрица) обрабатываются, программа не падает, а выводит сообщение и возвращается в меню.


## Формат ввода

Для каждой матрицы вводятся число строк и число столбцов, затем сами строки.
Каждая строка матрицы вводится одной линией, для каждого элемента нужно два числа через пробел: вещественная и мнимая часть.

Например, строка из двух элементов `1+2i` и `3-1i` вводится так:

```
1 2 3 -1
```

Десятичные дроби можно писать и через точку, и через запятую (`0.5` или `0,5`).

## Операции и условия

| Операция | Условие | Что происходит при нарушении |
|---|---|---|
| A + B | размеры матриц совпадают | сообщение об ошибке |
| A * B | число столбцов A равно числу строк B | сообщение об ошибке |
| A / B | B квадратная и невырожденная (det B ≠ 0), число столбцов A равно числу строк B | сообщение об ошибке |
| Транспонирование | нет | работает для любой матрицы |
| Определитель | матрица квадратная | сообщение об ошибке |


## Обработка ошибок

Программа не завершается аварийно при некорректных действиях пользователя: она выводит сообщение и возвращается к повторному вводу или в меню.

### Ошибки ввода

| Ситуация | Реакция программы |
|---|---|
| В меню введено не число или число вне диапазона 0–8 | Сообщение «Введите целое число от 0 до 8», ввод повторяется |
| Размер матрицы не является целым положительным числом | Сообщение «Введите целое положительное число», ввод повторяется |
| В строке матрицы неверное количество чисел | Сообщение «Нужно ввести ровно N чисел через пробел», повторяется ввод только этой строки |
| В строке матрицы не число (буквы, `NaN`, `Infinity`) | Сообщение «Некорректное число, повторите ввод строки», повторяется ввод только этой строки |
| При выборе матрицы введено не A и не B | Сообщение «Введите A или B», ввод повторяется |

### Ошибки операций

Классы `Complex` и `ComplexMatrix` сами проверяют условия и выбрасывают исключения с понятным текстом. Консольный интерфейс перехватывает `IllegalArgumentException` и `ArithmeticException` и выводит сообщение в виде «Ошибка: ...».

| Ситуация | Исключение | Сообщение |
|---|---|---|
| Сложение матриц разных размеров | `IllegalArgumentException` | указаны размеры обеих матриц |
| Умножение, когда число столбцов первой не равно числу строк второй | `IllegalArgumentException` | указаны оба значения |
| Деление на неквадратную матрицу или определитель неквадратной матрицы | `IllegalArgumentException` | сообщение о том, что операция определена только для квадратной матрицы |
| Деление на вырожденную матрицу (определитель равен нулю) | `ArithmeticException` | «Матрица вырождена, обратной не существует» |
| Деление на комплексный ноль внутри вычислений | `ArithmeticException` | «Деление на комплексный ноль» |

### Прочие случаи

- Если операция запрошена до ввода матриц, выводится подсказка («Сначала введите обе матрицы» или «Матрица A ещё не введена»), и программа возвращается в меню.
- Определитель вырожденной матрицы ошибкой не считается: программа выводит `0+0i`.
- Если ввод прерван (например, нажато Ctrl+D в Linux/macOS или Ctrl+Z в Windows), программа корректно завершается.
